# 🎮 Ultimate Gaming Carousel

A modern, responsive gaming carousel with auto-play, keyboard navigation, and sound effects.

## Features
- ✨ Auto-play with adjustable speed
- ⌨️ Keyboard navigation (arrow keys)
- 📱 Touch/swipe support for mobile
- 🎵 Optional sound effects
- 🌟 Beautiful glassmorphism design
- 📊 Real gaming content with ratings

## How to Use

1. Download the files: `index.html`, `styles.css`, `script.js`
2. Open `index.html` in your web browser
3. Enjoy exploring games!

## Controls
- **Click Arrows** - Navigate games
- **Click Dots** - Jump to specific game
- **Arrow Keys** - Keyboard navigation
- **Swipe** - Mobile navigation
- **Auto Play Button** - Toggle auto-rotation
- **Speed Slider** - Adjust rotation speed
- **Sound Button** - Toggle sound effects
